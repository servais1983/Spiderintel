# Politique de sécurité

## Versions prises en charge

La branche `main` et la dernière version publiée reçoivent les correctifs de sécurité.

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité exploitable dans une issue publique.

Utilisez la fonction de signalement privé de GitHub disponible dans l’onglet Security du dépôt. Incluez :

- la version ou le commit concerné ;
- les conditions nécessaires à la reproduction ;
- l’impact observé ;
- une preuve de concept minimale et non destructive ;
- toute proposition de correction disponible.

Les rapports seront examinés au mieux des disponibilités des mainteneurs. Aucun programme de récompense n’est actuellement proposé.

## Périmètre

Les problèmes de validation de cible, d’exécution de commandes, de gestion des secrets, de transport TLS, de permissions des rapports et de contournement de la confirmation d’autorisation sont considérés comme prioritaires.

Les vulnérabilités affectant exclusivement un outil tiers doivent également être signalées au projet concerné.
